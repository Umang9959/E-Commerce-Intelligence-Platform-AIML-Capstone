# Problem Statement

Online stores collect many transaction records, but those records are not directly useful for business decisions. This project converts retail transaction data into practical outputs:

- Which customers may stop buying?
- Which products should be recommended together?
- What could future sales look like?
- Which catalog items match a user search?
- What support answer can be generated from retrieved FAQ knowledge?

The final result is a Streamlit dashboard that demonstrates churn prediction, recommendations, sales forecasting, product search, support RAG, and monitoring.
